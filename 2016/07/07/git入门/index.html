git入门以及hexo的常用命令

撰写于 2016-07-07 修改于 2016-07-08 分类 编程技术

git入门

安装git 去Git官网下载。 安装成功后，在开始菜单里找到“Git”->"Git Bash",蹦出一个类似命令行的窗口的东西，就说明Git安装成功。 安装完成后设置：命令行输入： git config --global user.name"Your Name" git config --global user.email"email@example.com" 创建版本库 `git init`命令，初始化一个Git仓库。 `git add `可以添加多个文件。 `git commit -m "描述这个提交命令"`完成。 **时光机穿梭** `git status`查看仓库当前仓库的状况。 `git diff`具体查看修改了什么内容。 **版本回退** `git log`命令显示从最近到最远的提交日志。`git log --pretty=oneline`显示的信息要少的多。 `git reset --hard HEAD^``HEAD`表示当前版本，这个命令是回退到上一个版本。 `cat `查看文件内容 `git reset --hard commit id(版本号只要写前几位就可以了)` 列如`git reset --hard 3628164`即可回到指定的版本。 必须要记得commit id。`git reflog`查看命令历史，以便要回到未来的那个版本。 `git log`可以查看提交历史，以便确定要回退到哪个版本。 **工作区和暂存区** 工作区:就是你在电脑里能看到的目录，比如我的learngit文件夹就是一个工作区。 `git add`把文件添加进去，实际上就是把文件修改添加到暂存区; `git commit`提交更改，实际上就是把暂存区的所有内容提交到当前分支。 **撤销修改** `git checkout -- file`改动了工作区的某个文件的内容，直接丢掉工作区的修改。 `git reset HEAD file`回到上一步，按上一步的操作来。 最后如果已经提交了不适合的修改到版本库时，想要撤销本次提交，参考版本回退，不过没有推送到远程库。 **删除文件** `git rm `用于删除一个文件,并且`git commit`文件从版本库中被删除。 `git checkout -- test.txt`用于删错文件,版本库里还有，一键还原。 **添加远程库** 在本地的learngit仓库下运行命令： `git remote add origin https://github.com/tang-yue/zhinengshe.git` 注意这里origin会被占用，所以要换用其他的才可以成功添加。 `git push -u origin master`把本地库的所有内容推送到远程库上。 `git push origin master`推送最新修改。 **克隆一个远程仓库** `git clone https://github.com/tang-yue/gitskills.git`进入gitskills目录下就有github上的文件了。 **使用github** 在github上，可以Fork开源仓库;自己拥有Fork后的仓库的读写权限;可以推送pull request给官方仓库来贡献代码。 **创建与合并分支** `git branch`查看分支 `git branch `创建分支 `git checkout `切换分支 `git checkout -b `创建+切换分支 `git merge `合并某分支到当前分支 `git branch -d `删除分支 **解决冲突** 当Git无法自动合并分支时，就必须首先解决冲突。解决冲突后，再提交，合并完成。用`git log --graph`命令可以看到分支合并图。 **参考链接** [廖雪峰Git教程](http://www.liaoxuefeng.com/wiki/0013739516305929606dd18361248578c67b8067c8c017b000) ### hexo的常用命令 `hexo clean`清理database和/public目录，/public目录里是生成的静态文件数据。 `hexo generaet`简写是"hexo g"命令是用来生成静态页面的 会创建/public目录静态页面数据都在这个文件夹里。 `hexo deploy`一键部署命令上面在_config.yml文件中配置了部署信息，这个命令一键部署。 `npm install hexo-deployer-git --save`##安装部署所需要的插件 `npm install hexo-server --save`##安装server插件 `hexo n "my post"`新建文章 `hexo new page "pageName"`新建页面 **参考链接** [hexo系列教程](http://www.mashiro.io/2015/09/hexo-guide-3/) [hexo你的博客](http://ibruce.info/2013/11/22/hexo-your-blog/) [hexo搭建博客](http://blog.shijinrong.cn/2016/01/03/2016-01-03-how-to-build-blog/) ### markdown语法 **建立代码块**：建立代码区块只要简单地缩进4个空格或是一个制表符即可。 **邮箱**: ![markdown语法速记](/../markdown.png) **参考链接** [十分钟学会markdown](http://i.cmgine.net/archives/12291.html)
